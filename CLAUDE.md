# Arbeitsweise für dieses Repository

- `main` ist die Live-Website (GitHub Pages, https://dekoluxury.world).
- Änderungen **nie direkt auf `main` pushen**. Immer einen eigenen Branch anlegen und einen
  **Pull Request** öffnen. Der Inhaber prüft und führt ihn selbst zusammen.
- Texte, Kommentare und Pull-Request-Beschreibungen auf Deutsch, einfach und verständlich.
